# The Expert Hour · Sales page

Static site. `index.html` is self contained; `assets/` holds the logo and speaker photos.

## Host on GitHub Pages
1. Create a repo and upload the contents of this folder (index.html at the root).
2. Settings → Pages → Deploy from branch → `main` / root.
3. Your page will be live at `https://<user>.github.io/<repo>/`.

## Before launch
- Hero video and poster image: set in the editor, then re-export.
- Speaker photos: replace files in `assets/` with clean headshots (same names) if desired.
